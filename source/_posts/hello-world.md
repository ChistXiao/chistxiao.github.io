## 为什么要写博客

把零散的想法写下来，才知道自己到底想清楚了没有。所以这个站点的定位很简单：

1. **记录** —— 学到的东西、踩过的坑，趁记忆还热乎。
2. **整理** —— 写下来就是一次复盘，知识才真正变成自己的。
3. **分享** —— 如果刚好能帮到路过的人，那就更好了。

## 这个站点怎么搭的

```bash
# 新建文章
hexo new "文章标题"

# 本地预览，访问 http://localhost:4000
hexo server

# 推送到 GitHub，由 Actions 自动构建并发布
git add .
git commit -m "post: 新文章"
git push
```

整个流程里最舒服的一点是：**只写 Markdown**。剩下的构建、发布都交给 GitHub Actions 处理，写完推送即可上线。
